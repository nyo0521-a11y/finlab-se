入院や手術で医療費が高額になっても、公的保険の高額療養費制度があるから大丈夫——そう聞いて安心している方は多いと思います。

ただ、2026年8月にこの制度が変わると聞いて調べ始めると、途中で手が止まる論点がいくつも出てきます。

- 自己負担の上限がいくらに上がるのか、自分の年収だといくらなのかが分からない
- 新しくできる「年間上限」が、自分にも自動で適用されるのかが分からない
- 結局、医療費のために現金をいくら持っておけばいいのかが分からない

<strong>2026年8月の改正で、医療費の「最悪ケース」にようやく金額が付きます。</strong>年収約770万円以下（住民税非課税を除く）の会社員なら、公的保険が効く医療費の自己負担は年53万円が上限です。青天井ではない、という数字がはっきりします。

ただし、この年間上限は誰にでも自動で効くわけではありません。数える期間が「8月から翌年7月」と決まっているため、発症した月がズレると上限に届かないまま期間が切り替わり、<strong>上限が一度も適用されないことがあります</strong>。常に効かないという話ではなく、発症月次第で空振りする、という話です。しかも、申し出なければ戻ってきません。

本記事では厚生労働省の審議会資料をもとに改正後の金額を整理し、上限が空振りするケースを実際の計算で確認していきます。なお本記事は、特定の保険商品を推奨するものではありません。制度の数字を家計の判断材料に変えることに絞って解説します。

※本記事は2026年7月時点の厚生労働省資料に基づきます。金額は今後の政令改正で確定します。

## 2026年8月、月額の自己負担上限はいくらになるか

まず土台から確認します。高額療養費制度は、1か月（1日〜末日）に窓口で払った医療費が一定額を超えたとき、超えた分が戻る仕組みです。この「一定額」が2026年8月から引き上げられます。

70歳未満の5区分は次のとおりです。

| 年収の目安 | 現行の月額上限 | 2026年8月〜 | 引き上げ率 |
|---|---|---|---|
| 約1,160万円超 | 252,600円＋1% | 270,300円＋1% | +7.0% |
| 約770〜1,160万円 | 167,400円＋1% | 179,100円＋1% | +7.0% |
| 約370〜770万円 | 80,100円＋1% | 85,800円＋1% | +7.1% |
| 約370万円以下 | 57,600円 | 61,500円 | +6.8% |
| 住民税非課税 | 35,400円 | 36,900円 | +4.2% |

※金額はとりまとめ時点のもので、最終的には政令等で確定します。

表の「＋1%」は、医療費が一定額を超えた部分の1%を上乗せするという意味です。現行の起点は267,000円ですが、<strong>改正後の起点は資料に記載がなく確認できませんでした</strong>。ここは推測で書かず、確定を待つ扱いにします。

2点、誤解しやすいところを補足します。

1つは引き上げ幅です。報道で見かける「4〜38%の引き上げ」は、2027年8月に予定されている所得区分の細分化（5区分→13区分）まで含めた数字です。<strong>2026年8月時点の引き上げは、上の表のとおり4.2〜7.1%にとどまります</strong>。

もう1つは有効期間です。この「85,800円」などの金額は、2026年8月から2027年7月までの1年間のものです。2027年8月には区分がさらに割れ、たとえば現在の「約370〜770万円」は、約370〜510万円（85,800円＋1%）・約510〜650万円（98,100円＋1%）・約650〜770万円（110,400円＋1%）の3つに分かれる予定です。

## 年間上限はいくらか。そして自動では戻らない

今回の改正で新しく入るのが「年間上限」です。これがこの記事の主役になります。

この制度には経緯があります。2024年12月に決まった当初案は、2025年3月に患者団体の反発を受けて凍結されました。その後、患者団体を委員に加えた専門委員会で再設計され、2025年12月にとりまとめに至っています。<strong>年間上限は、凍結後に追加された配慮措置</strong>という位置づけです。撤回ではなく、作り直して復活した制度だと理解しておくと、内容が読みやすくなります。

### 年間上限の金額と、区分がまたぐ理由

年間上限は次のとおりです。

| 年収の目安 | 年間上限 |
|---|---|
| 約1,160万円超 | 168万円 |
| 約770〜1,160万円 | 111万円 |
| <strong>約770万円以下（住民税非課税を除く）</strong> | <strong>53万円</strong> |
| 住民税非課税 | 29万円 |

※2027年8月の区分細分化で年収約200万円未満は年間上限41万円（償還払い）になる予定です。70歳以上で一定所得以下の方は18万円です。金額はとりまとめ時点のもので、最終的には政令等で確定します。

注目したいのは<strong>53万円という区分の広さ</strong>です。2026年8月の時点では、住民税非課税を除き<strong>年収約770万円までが一律で53万円</strong>になります。会社員の多くはこの範囲に入るはずなので、まずは「自分は53万円だろう」と当たりを付けておけば大きく外しません。

なお、月額上限は約370万円のところで区切りが変わり、2027年8月にはさらに細かい13区分に分かれる予定です。一方の年間上限は、その細分化のあとも約770万円以下が53万円のまま共通で、変わるのは年収約200万円未満が41万円になる点だけです。区分の細かさが月額と年間で違う理由は、資料では説明されていません。

資料では、年間上限53万円の月額平均が約44,200円（53万円÷12）と示されています。これは後述する「多数回該当」の月額44,400円を12か月続けた532,800円とほぼ同じ水準です。<strong>毎月上限に達し続けた1年分に金額を合わせた設計</strong>と読めます。

なお、年間上限を数える対象には、月額上限に届かなかった月の自己負担も通算されます。毎月上限に達するような重い治療でなくても、積み上がった分はカウントされるということです。

### 自動では戻らない。申し出が前提の後払い

ここが最も見落とされやすい点です。<strong>年間上限は、本人からの申し出が前提で、後から精算する形になります。</strong>黙っていても口座に振り込まれる制度ではありません。申請手続きの具体的な内容は資料の段階では固まっておらず、施行に向けて詰められる見込みです。

一方で、月額の上限には事前手続きの道があります。両者は扱いが違うので、整理しておきます。

| | 手続き | 窓口での支払い |
|---|---|---|
| 月額上限（事前手続きあり） | 限度額適用認定証、またはマイナ保険証での情報提供に同意 | 最初から上限額までで済む |
| 月額上限（事前手続きなし） | 後から申請 | いったん3割分を全額払い、後で差額が戻る |
| <strong>年間上限（新設）</strong> | <strong>本人からの申し出（詳細は未確定）</strong> | <strong>後からの精算</strong> |

限度額適用認定証は、健康保険証と一緒に病院の窓口に出すことで、支払いを最初から上限額までに抑えられる書類です。マイナ保険証を使う場合は、窓口で情報提供に同意すれば同じ扱いになります。<strong>入院が決まった時点で手続きしておけば、立て替える金額そのものを小さくできます</strong>。年間上限が後払いである以上、この事前手続きの価値はむしろ上がります。

## 発症月がズレると、新設された年間上限が空振りする

ここからが本題です。年間上限を数える期間は「8月から翌年7月」と決められています。この記事ではこれを算定期間と呼びます。年間上限を数えるための1年間の区切り、という意味です。

計算の前に、もう1つだけ用語を押さえます。<strong>多数回該当</strong>です。直近12か月のうち3回上限に達すると、4回目からは上限額が下がる仕組みで、年収約370〜770万円の区分では月44,400円になります。長引く治療ほど月々の負担は軽くなる、という配慮です。

この2つを合わせると、発症月による差が見えてきます。年収約370〜770万円の方が、医療費が月およそ29万円（窓口3割負担で約8.7万円）かかり、自己負担が月額上限85,800円をわずかに超える状態が12か月続いたと仮定して計算します。

<strong>ケースA：8月に発症した場合</strong>

| 期間 | 計算 | 自己負担 |
|---|---|---|
| 8・9・10月 | 85,800円×3 | 257,400円 |
| 11月〜翌7月（9か月） | 44,400円×9 | 399,600円 |
| 合計 | | 657,000円 |
| 年間上限53万円を適用 | | <strong>530,000円</strong> |

12か月がまるごと1つの算定期間（8月〜翌年7月）に収まるため、年間上限が効きます。127,000円が軽くなりました。

<strong>ケースB：4月に発症した場合</strong>

| 算定期間 | 計算 | 自己負担 |
|---|---|---|
| 期間1（4〜7月） | 85,800円×3＋44,400円 | 301,800円（53万円未満） |
| 期間2（8月〜翌3月・8か月） | 44,400円×8 | 355,200円（53万円未満） |
| 合計 | | <strong>657,000円</strong>（上限の適用なし） |

同じ病気、同じ治療期間、同じ医療費です。それでも12か月が2つの算定期間に分断され、<strong>どちらの期間も53万円に届かないまま終わります</strong>。結果、年間上限は一度も適用されません。

差額は127,000円、負担は約1.24倍です。家族で1回旅行に行ける程度の金額が、発症した月という自分では選べない条件で変わります。

計算の前提を明記しておきます。

1. 毎月ちょうど月額上限に達する状態が続く、という単純化した試算です
2. 「＋1%」の加算分はゼロとして計算しています
3. 多数回該当のカウントは直近12か月で見るため、8月の算定期間の切り替えではリセットされない、という前提を置いています

3点目は資料に明文がなく、制度の建て付けから読み取った前提です。詳細は今後の政令等で確定します。ただし<strong>仮に8月でリセットされる場合でも、結論は変わりません</strong>。その場合ケースBは期間1が301,800円、期間2が479,400円（85,800円×3＋44,400円×5）となり、やはりどちらも53万円に届かず、合計781,200円で約1.47倍に開きます。どちらの解釈でも「空振りする」という話であり、リセットされる解釈のほうが差はむしろ大きくなります。

ちなみに「53万円の上限が2回発生して106万円になる」というケースは、まず起こりません。1か月で53万円の自己負担に達するには単月で約4,500万円規模の医療費が必要で、これは超高額薬剤を単月処方されるような限られた場合に限られるためです（厚労省資料でも、薬価約4,960万円の遺伝子治療薬を単月処方されたケースが年間上限の対象例として示されています）。

なお、毎月上限に達する状態が1年続くのは、がん治療や長期入院など限られたケースです。ここで見ているのは、あくまで最悪ケースの輪郭になります。

## 年間上限で本当に助かるのは誰か

年間上限の新設は、全員にとってのプラスではありません。自分がどちら側かを知っておくと、受け止め方が変わります。

<strong>1か月だけ上限に達するタイプの人は、負担が増えます。</strong>短期の入院や手術がこれに当たります。年間上限に届かないことがほとんどで、恩恵はありません。一方で月額上限が80,100円から85,800円へ上がるため、5,700円ほど負担が重くなります（厚労省の試算例でも、単月のみ該当する方の増加は年約0.6万円とされています）。年に1回のことであれば、影響はこの金額にとどまります（年収約370〜770万円の場合）。

<strong>逆に大きく助かるのは、月額上限には届かないものの、通院が長く続いている人です。</strong>年間上限は月額上限に達しない月の自己負担も通算するため、ここが効きます。厚労省の試算例では、毎月7万〜8万円の自己負担が12か月続く方（年76.7万円）の負担が53万円で頭打ちになり、<strong>年約23.7万円軽くなる</strong>とされています。

まとめると、今回の改正は<strong>「短期・単発の人が少し多めに負担し、長期で治療を続ける人の負担を抑える」</strong>方向の見直しだと読めます。自分がどちらに近いかで、備え方の優先順位も変わってきます。

## 「年間上限額＝用意すべき貯蓄額」ではない

年間上限が分かると、53万円さえあれば安心と考えたくなります。ただ、そこはもう一段だけ慎重に見ておく必要があります。<strong>高額療養費の対象は、あくまで公的保険が効く医療費に限られる</strong>からです。

対象外になる主な費用は次のとおりです。

- <strong>差額ベッド代</strong>：本人の希望で個室や少人数部屋に入ったときにかかる部屋代
- <strong>入院時の食事代の自己負担分</strong>：入院中の食事にかかる定額の負担
- <strong>先進医療</strong>：公的保険の対象になる前の段階にある治療
- <strong>自由診療</strong>：公的保険を使わずに受ける治療

このうち差額ベッド代は、金額の幅が大きく、家計への影響も読みにくい費目です。ここには押さえておきたい前提があります。厚生労働省の通知では、<strong>本人の同意書による確認がない場合、患者に支払い義務はないとされています</strong>。治療上の必要があって個室に入った場合や、病院側の都合で個室になった場合も同様です。同意書にサインする前に、金額と必要性を確認しておくことが自衛になります。

つまり、備えるべき金額は「年間上限53万円」ではなく、そこに対象外の費用を足したものになります。年間上限は天井そのものではなく、<strong>天井の一部に金額が付いた</strong>という理解が正確です。

## 民間の医療保険より先に、生活防衛資金を「計算」で用意する

ここまでの数字を家計の話につなぎます。

改正後の最悪ケースは、公的保険が効く医療費に限れば年53万円です。ただし<strong>発症月がズレて年間上限が空振りすれば、同じ治療でも実質65.7万円</strong>まで膨らみます。さらに差額ベッド代などが乗ります。備えを考えるなら、53万円ではなくこの膨らんだ側の数字を基準にするのが安全です。

この金額を貯蓄で持つか保険で持つかが分かれ道になります。判断の軸はシンプルで、<strong>頻度が高く、生活費と同じスケールで済むものは貯蓄で持つ</strong>という考え方です。

保険料には保険会社の運営費が含まれるため、加入者全体で見れば受け取る額は払い込む額を下回ります。だから保険は期待値で買うものではなく、<strong>頻度は低いけれど、起きたら自力ではとても払えない損失にだけ使う道具</strong>です。この基準に照らすと、年間で数十万円という金額は「自力で払える範囲」に入ってきます。

私自身も、内容を確認したうえで自分の医療保険を解約しました。貯蓄と高額療養費制度で対応できると判断したためです。ただし<strong>妻の保険は継続しています</strong>。制度上は不要という結論が出ても、家族の納得は別の問題だからです。

もう1つ、医療費だけでなく収入が止まるリスクも見ておいてください。会社員には、病気やケガで働けない間に給与の一部が支給される傷病手当金がありますが、支給までには時間差があります。この空白を埋めるのが、働けなくなったときに生活を支えるための現金、いわゆる生活防衛資金です。必要な月数の考え方は[ボーナス投資前に確認したい4つのチェックポイント](https://finlab-se.com/posts/bonus-investment-checkup-4steps/)で整理しています。

## まとめ — 最悪ケースに数字が付いた意味

2026年8月の改正を、家計の視点で整理します。

- 月額の自己負担上限は4.2〜7.1%引き上げられる（報道の「4〜38%」は2027年8月の細分化まで含めた数字）
- 年間上限が新設され、年収約770万円以下（住民税非課税を除く）は53万円。ただし自動では戻らず、申し出が前提の後払い
- 算定期間が8月〜翌年7月のため、発症月がズレると上限に届かないまま期間が切り替わり、空振りすることがある
- 年間上限額は用意すべき貯蓄額そのものではない。差額ベッド代などは対象外

一番の価値は、医療費の最悪ケースに<strong>感覚ではなく数字が付いた</strong>ことだと考えています。金額が分かれば、保険で備えるか貯蓄で備えるかを計算で判断できます。

今日のネクストアクションは1つです。<strong>自分の年収区分の月額上限と年間上限をメモし、その金額を今の預金からすぐ払えるかを確認してください。</strong>年間上限は後払いなので、実際に要るのは「いったん立て替える現金」です。あわせて限度額適用認定証やマイナ保険証の手続きを確認しておけば、立て替える金額そのものを小さくできます。

支出の全体像から見直したい方は、[投資を始める前にやるべき支出の最適化](https://finlab-se.com/posts/expense-optimization-before-investing/)も参考にしてみてください。何かの参考になれば幸いです。
