# サムネイル ベース画像生成プロンプト

記事: 不動産クラウドファンディングで貸し倒れを経験した話——評価額は自分で確認すべきだった
ファイル: `static/images/thumb-realestate-cf-default-base.png`

## 使い方

1. **新しいChatGPT会話**を開始（過去の文脈を引きずらないため）
2. 既存サムネ1〜2枚（`thumb-sbi-securities-honest-review.png` 等）を添付し「このテイストで作って」と伝える
3. 以下のプロンプトをコピペして渡す
4. 生成されたベース画像をDownloadsに保存し、Claudeに「ベース画像を保存した」と伝える

---

```
日本語の個人投資ブログ用のサムネイル画像（1376×768px・16:9・横長）を作成してください。

【重要：これは「不動産クラウドファンディングで貸し倒れ（デフォルト）を経験し、募集時の不動産評価額を自分で検証することの大切さに気づいた実体験レビュー」に関する記事のサムネイルです。高配当株・暗号資産とは無関係です。白背景のインフォグラフィックではなく、シネマティックなダークCG調の画像を作成してください。】

【画像全体の雰囲気】
- ダークネイビーから漆黒のグラデーション背景（#050C23 → #0A1A4A）
- 高級感のある金融テックの世界観（BloombergやNikkeiの金融ビジュアルに近い）
- 全体に薄い回路パターン／グリッドラインを敷く（深い青色で控えめに）
- 写真のようなリアル3D CG調
- テキスト・ロゴ・ラベルは一切入れないこと
- 後でテキストを左側に重ねるので、画面左45%は暗く保ち、目立つオブジェクトを置かないこと

【ビジュアル構成】
画面右55%のエリアに、以下を配置：
- 中央：浮かび上がる立体的な土地の区画（発光するワイヤーフレームの敷地・建物ブロック）の上に、大きな虫眼鏡（またはスキャンするような光の走査線）が重なり、区画の価値を検証しているようなイメージ
- 区画の脇に、高さの異なる2本の発光する棒（バーグラフ風の柱）を配置し、片方は低く小さく、片方は大きく高い——「募集時に示された評価額」と「実際の相場」に差があることを暗示する（数字やラベルは入れない）
- アクセント色：エメラルドグリーン #4ADE80、アンバーゴールド #F59E0B
- 全体に小さな発光粒子（緑・金）を漂わせる
- 放射状のソフトグロー

【画面左45%エリア】
- 暗いまま保ち、薄いグリッドラインだけが見える程度
- 目立つオブジェクトを置かない（後でテキストを重ねるため）

【カラーパレット】
- 背景：#050C23 → #0A1A4A
- メイン：#4ADE80（エメラルドグリーン）／#F59E0B（アンバーゴールド）
- 粒子：緑と金の混色
- グリッドライン：深い青、非常に薄く

【サイズと形式】
- 1376×768px のPNG
- アスペクト比 16:9 横長
- テキスト・ロゴは絶対に入れないこと

【絶対にやらないでほしいこと】
- 白背景のインフォグラフィックにしない
- 4分割やテーブル形式のレイアウトにしない
- ✓や✗のチェックマークを入れない
- 株価チャート・コインの山（高配当株記事との差別化のため）を入れない
- 実在の不動産会社のロゴ・実際の住所や地図を入れない
```
