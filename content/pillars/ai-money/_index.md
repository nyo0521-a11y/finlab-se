Claude Code を中心とした<strong>AIツールを使った家計・資産管理の自動化</strong>、シミュレータ自作、ブログ運営への活用事例を、金融SEの実装視点でまとめます。

「AI活用」というと抽象的になりがちですが、本テーマでは「実際に作って、運用している」事例だけを記録しています。

## こんな困りごとに答えます

家計・資産管理の「手作業が続かない」場面から読み始められます。

- <strong>毎月の資産記録が続かない</strong> — 残高更新からスプレッドシート、貸借対照表までの3ステップを、コードを書かずに指示だけで回している実例です → [Claude Codeで資産記録を自動化した](https://finlab-se.com/posts/asset-management-claude-code/)
- <strong>家計簿をつけても、FIREにいくら必要かが見えてこない</strong> — 費目別ではFIRE設計ができない理由と、支出を「生存費／豊かさ費」の2分類に仕分けた1年分の実データを公開しています → [Claude Codeで「FIRE家計簿」を作る](https://finlab-se.com/posts/claude-code-fire-budget/)
- <strong>配当金がいつ・いくら入るのか把握できていない</strong> — 保有銘柄CSVから月別の配当キャッシュフロー表を作り、配当の谷月・山月から買い増しを考える手順です → [Claude Codeで「配当金カレンダー」を自動生成](https://finlab-se.com/posts/claude-code-dividend-calendar/)
- <strong>取り崩しを始めて資産が尽きないか不安</strong> — 無料シミュレーターで自分の計画の成功率を数値化する方法と、4%ルールの前提を整理しています → [取り崩しシミュレーション無料ツールの使い方](https://finlab-se.com/posts/montecarlo-tool-usage/)／[4%ルールは守りすぎ？モンテカルロシミュレーションで考える取り崩し戦略](https://finlab-se.com/posts/montecarlo-background/)
- <strong>「AI資産運用」に任せて大丈夫なのか判断できない</strong> — ロボアドバイザーの中身と、AIにできること・できないことの境界線を初心者向けに整理しています → [AI資産運用とは？ロボアドは本当にAIなのか](https://finlab-se.com/posts/ai-asset-management-robo-advisor-2026/)

AIに任せてよい作業と、自分で判断すべき投資判断の線引きを意識して書いています。
