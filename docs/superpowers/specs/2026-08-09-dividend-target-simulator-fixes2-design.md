# 配当目標逆算シミュレーター 再指摘対応 設計書

## 背景

前回のA/B分離改修を本番公開後、ChatGPTに再レビューを依頼したところ、5件の指摘を受けた。実コード（`static/tools/dividend-target-simulator/index.html`、本番稼働中）を確認し、すべて実在する問題であることを確認した。

| # | 指摘 | 重要度 |
|---|---|---|
| 1 | 税引後モードを選んでも、チャートの配当額系列は常に税引前の値で描画される。税引後入力時、チャートの最終年の値が入力した目標額より大きく見えてしまう | 高 |
| 2 | チャートの灰色「累計投資額」棒グラフはY0にA+B全額を表示するが、緑の配当折れ線はBの寄与を投資期間の中間時点(t=years/2)から開始する設計に変更済み（前回の改修）。両者の前提が矛盾している | 高 |
| 3 | `n_target`（目標配当額）の入力欄は上限超過時に表示が同期するよう修正済みだが、`n_current`（現在配当）・`n_futureNow`（A）・`n_futureLater`（B）の3欄は同じ修正が入っておらず、上限超の値を入力すると表示と内部計算がズレたままになる | 中 |
| 4 | Bの増配成長を「投資期間の半分」とする前提の説明文が「控えめに」という表現になっているが、実際には投資タイミングの前半/後半どちらに寄るかで保守的にも楽観的にもなりうるため不正確 | 中 |
| 5 | 結果表示の「いま買うべき平均配当利回り」という文言は、実際にはA（今すぐ）だけでなくB（将来購入予定分）にも同じ利回りを適用しているため、表現として正確性を欠く | 低 |

## 対応方針

### 1. 税引後モードとチャートの整合（ユーザー承認: チャートも税引後金額に合わせる）

`buildChartData()`が計算する配当額系列（`divArr`、緑の折れ線）は、内部的に`calcRequiredYield()`が返す税引前ベースの必要利回り(`r.y`)を使っている。`state.isAfterTax`が`true`の場合、表示用の配当額を`NET_FACTOR`（0.79685）で税引後換算してからチャートに渡す。

投資元本（灰色の棒グラフ、`principalArr`）は税金の対象ではない（まだ配当を生んでいない投資元本そのもの）ため、税引後換算の対象外とする。

### 2. 累計投資額グラフの投資タイミング整合（ユーザー承認: Y0=Aのみ、中間時点以降=A+B）

現在`buildChartData()`は`principalArr`に`t===0`のときだけ`A+B`の合計を1点だけ描画している（それ以外は`null`）。

変更後は2点描画する：
- `t=0`: `A`（今すぐ投資できる金額）のみ
- `t = Math.ceil(years/2)`: `A+B`（B分の投資が実行されたとみなす中間時点）

`Math.ceil(years/2)`は、既存の`divFutureLater`のB発生条件（`t < years/2`が偽になる最初の整数年）と完全に一致させるための式で、配当の折れ線グラフとタイミングを揃える。

### 3. 入力欄の上限同期・文言修正（機械的な修正、判断不要）

**3-a. 上限同期バグの横展開**

前回`n_target`に適用した「上限超過時のみ即時同期・下限クランプはblur(change)時に適用」パターンを、以下の3つの入力欄にも同様に適用する：
- `n_current`（現在の年間配当額、min=0, max=10000）
- `n_futureNow`（A、min=0, max=100000）
- `n_futureLater`（B、min=0, max=100000）

**3-b. 「控えめに半分の期間」の文言修正**

`index.html:356`の説明文を、投資タイミングの前提を正確に表す文言に変更する：
- 変更前: 「今後投資予定額」は投資タイミングが未定のため、控えめに投資期間の半分の期間だけ増配成長したものとして計算します。
- 変更後: 「今後投資予定額」は投資タイミングが未定のため、便宜上、投資期間の中間時点で一括投資したものとして計算します。

**3-c. 「いま買うべき」表現の修正**

`index.html:294`（イントロ文）と`index.html:388`（結果ヒーローセクションのリード文）の「いま買うべき」を、A・B全体の平均購入利回りであることが伝わる表現に変更する：
- イントロ文: 「いま買うべき平均配当利回り」→「目標達成に必要な平均配当利回り」
- ヒーローリード文: 「あなたの目標に届くために、いま買うべき」→「あなたの目標に届くために、必要な」
